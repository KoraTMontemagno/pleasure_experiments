# Pipeline for psychometric experiment with pleasure

Here you can find some attempts at estimating sex pleasure threshold using [PsiMarginal](https://github.com/NNiehof/Psi-staircase/tree/master)
by Nynke Niehof and James Cooke, Radboud University Nijmegen. 

Users can provide responses through PsychoPy.

Any type of sex toy compatible with Intiface and capable of vibration can be connected, as the code uses [buttplug](https://buttplug.io/).
